PhantomSMS — Developer Examples

Sample code, quick start, and docs for integrating SMS functionality (example placeholders).

Quick start

Open the examples/ folder for ready-to-run examples in Python, Node.js, and PHP. Replace the PHANTOMSMS_API_BASE placeholder and your API key before running.

  • Python: python3 examples/python.py
  • Node.js: node examples/nodejs.js (Node 18+ or install node-fetch)
  • PHP: php examples/php.php

Examples

The examples included are intentionally minimal, developer-friendly, and documented inline. They use a placeholder base URL constant PHANTOMSMS_API_BASE — replace it with your API base URL.
